# 冷门创新硬件的发现与筛选

扩展目标是寻找更多独立任务、差异化明显的消费AI硬件，尽可能达到千级规模；数量目标不用于降低AI、消费用途、销售证据或去重标准。

## 已建立的发现线索

本轮按CES官方已有年份与分页链接整理2024–2026三个年度，共1,382条奖项目录记录，并成功读取其中1,374条产品说明。说明中608条出现AI、机器学习、神经网络或计算机视觉等相关文字；消费相关类别的初步候选池为267条。这些是文本筛选结果，不是已经核实的消费AI硬件数量，也不代表所有AI产品一定出现这些词。

[查看线索索引](../content/discovery/ces-award-leads.json) · [CES官方创新奖目录](https://www.ces.tech/ces-innovation-awards)

奖项资料用于发现产品与品牌。[CTA评奖说明](https://cta.secure-platform.com/ces-awards)明确奖项不提供产品测试或背书，获奖也不能证明产品在核查日仍可购买。数据中的工业设备、医院设备、纯软件、元器件、普通联网产品和旧款，需要进一步筛选。

## 正式收录需要补齐

1. 确认是个人、家庭或个人创作者可以使用和订购的实体电子产品。
2. 找到具体AI功能及运行依赖，不能只依据“智能”、联网、定时或一般自动化宣传。
3. 打开品牌或明确购买渠道核查销售、预售、租赁或预约状态；保留地区与交付条件。
4. 说明与已有目录相比，独立需求或实现方式究竟有什么实质差异；合并配色、容量、套餐和近似升级。
5. 完成八项详析、国内购买信息、资料来源、产品与参考图、独立AI概念图，以及供应链候选关系。

只有完成核查的产品进入对应状态的目录。原始线索不冒充现货，付费预约不冒充正式订单，尚未找到证据的字段保持明确边界。

## 已保存的筛查案例

[查看逐项筛选记录与来源](hardware-screening.md)。记录包含复核后收录、同任务保留代表、销售待核和AI作用尚不明确等情况；它是本轮保存的事件样本，不代表已对全部线索逐一完成审计。型号、地区和渠道发生变化后可以重新评估，并保留此前判断。

场景分组同样接受修订。例如不同录音输入方式放在谈话记录与整理组，喂食器、鸟浴与巢箱放在庭院鸟类影像观察组；独立档案继续解释各自实现差异。分组依据保存在[需求合并记录](../content/hardware/need-aliases.json)，产品数量与核心需求数量分别计算。
