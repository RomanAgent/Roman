## 先把这次创业的边界写清楚

已明确的业务背景是：在深圳开展AI智能硬件与玩具业务，兼顾国内生意和跨境电商，并考虑未来境外融资。本章同时比较一位创始人和有合伙人的情况。还没有在这篇记录中确认具体公司名称、股权比例、注册资本、现有店铺归属、投资人要求和实际注册结果。

公司注册首先是在分配责任：谁雇人、谁拥有设计与代码、谁向工厂下单、谁对消费者出售、谁收钱并开具相应票据、谁承担数据处理和售后义务。注册地只是其中一项选择。对于有研发、库存、儿童互动和跨境销售的产品，把这些角色先写在一页纸上，比先购买几个注册套餐更能减少后续返工。

## 什么业务，由哪个主体承担

**一种可讨论的业务分工，不是已确定的股权结构**

1. **深圳经营主体**：研发与用工、工厂采购、国内店铺、发票和税务；按实际资质承担出口与售后。
2. **境外经营主体（按需）**：真实境外销售合同、结算、当地业务或投资人要求；与深圳公司之间保留有实际内容的交易。
3. **客户与目标市场**：消费者、平台、进口责任人及当地合规安排；公司成立并不自动完成产品准入。

箭头表达业务衔接，不表示一定要设两家公司或由哪家公司控股。收款平台账户、商标与进口责任人也不是同一种“主体”。

**把容易混在一起的角色拆开**

| 角色／业务 | 可讨论的承接方式 | 必须确认的责任 |
| --- | --- | --- |
| 深圳研发、采购和团队 | 深圳有限公司通常更容易对应真实人员、场地与成本 | 劳动用工、成果归属、模具和库存、工厂质量与供应合同 |
| 国内电商店铺与开票 | 符合平台资格的境内主体 | 卖家身份、发票、售后、产品质量及税务；经营范围不能替代许可证 |
| 出口与境外销售合同 | 境内公司直接出口，或经具真实业务的境外销售主体 | 实际卖家、货权、出口申报、外汇收款及关联交易的证据链 |
| 独立站／跨境平台卖家 | 按具体平台、市场与控制人条件选择可入驻主体 | 商户名、合同、退款方及收款账户应有清楚关系；买来的账号不解决合规 |
| 商标、代码、外观和模具 | 由明确权利人持有，再通过合法许可／转让支持其他主体 | 付款给ODM不自动获得完整源码、形象版权或全球商标权 |
| 美国进口认证与欧盟责任人 | 按进口链路和目标市场规则安排合资格承担者 | 不等同于“再注册一家当地公司”；检测机构、报关行和责任人各有范围 |
| App、语音与云端模型 | 由明确的服务提供者／数据处理者签约并管理供应商 | 处理目的、录音保存、儿童同意、模型训练、跨境路径及服务终止方案 |
| 境外融资与股权激励 | 根据具体投资人和中国侧合规意见设计 | 经营公司与融资控股公司可能不同；境外注册不自动完成外投、返程或税务手续 |

依据：[1] [CPSC：Children’s Product Certificate FAQ](<https://www.cpsc.gov/FAQ/CPC>) · [2] [欧委会：GPSR商业义务问答](<https://webgate.ec.europa.eu/safety/consumers/consumers_safety_gate/obligationsForBusinesses/documents/Q%26A.pdf>) · [3] [个人信息保护法](<https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm>)

例如，香港公司向海外客户出售一款由深圳团队设计、东莞工厂生产的玩具，并不能只留一份香港销售发票。仍需解释谁向工厂采购、谁拥有货物和商标、深圳研发由谁付费、消费者向谁退款、谁承担进口和产品责任。合法转售可以存在多份合同与发票，重点是每一段都对应真实业务，而不是为了把利润留在某处临时编造费用。

## 独资与合伙：先处理人、钱和IP

没有合伙人时，可以讨论一个股东的有限责任公司。“一人有限公司”与个人独资企业不是同一种法律形式，不应混用责任结论。对于承担研发、用工、产品销售和未来融资的业务，本章以有限公司作为主要比较对象；具体是否采用其他形式，需结合实际业务另行评估。符合条件的小公司可以依法简化董事、监事设置，经法定条件和必要的股东决定落实，不必为凑人数安排无实际职责的人挂名。

依据：[4] [市场监管总局：现行公司法](<https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_067c072db6ef4679a2e0180996be4cf8.html>)

新设有限责任公司的认缴资本是股东承诺投入公司的财产，不是交给中介的注册费。现行公司法一般要求从成立之日起五年内按章程缴足；公司不能清偿到期债务时，未届期出资也可能被要求提前缴纳。不要为显示实力填一个无法承担的数额；特殊行业和许可要求另核。旧公司的过渡安排不能套给2026年新公司。

依据：[4] [市场监管总局：现行公司法](<https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_067c072db6ef4679a2e0180996be4cf8.html>)

**两种情况都要在登记前谈清**

| 问题 | 没有合伙人 | 有真实合伙人 |
| --- | --- | --- |
| 财产与责任 | 独立公司账、合同、资金凭证及书面股东决定；仅一个股东时还涉及公司财产独立的举证要求 | 资金、报销、借款和出资分别记清；多人持股也不能以财产混同或滥用法人独立地位逃避责任 |
| 出资与贡献 | 按真实投入能力安排认缴额、期限和资金来源 | 现金、可依法出资的知识产权、持续劳动贡献分别处理；“技术股”不能只口头约定 |
| 决策与僵局 | 确认本人、董事和被授权经办人的权限 | 明确日常权限、重大事项、董事安排和僵局机制；51%不意味着所有事项都能单独决定 |
| 退出与未来融资 | 提前整理个人创作、公司资产与未来激励的边界 | 约定离职、未完成承诺、转让、回购或分期取得的可执行方案；增资稀释与员工激励也要谈 |
| 账户与印章 | 关键权限可由本人接管，留存公司账套和凭证 | 公司邮箱、网银、税务、店铺、代码仓库和印章按权限管理，避免退出时被个人账号锁住 |
| 知识产权 | 把成立前已有代码、形象、域名、商标和模具列成清单 | 每位创始人、员工、外包和工厂分别确认权利与交付；不是所有“帮项目做的东西”天然属于公司 |

依据：[4] [市场监管总局：现行公司法](<https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_067c072db6ef4679a2e0180996be4cf8.html>) · [5] [计算机软件保护条例](<https://xzfg.moj.gov.cn/mobile/law/detail?LawID=581>)

委托软件开发的权属应写进合同：没有书面约定或约定不明时，法律并不当然把著作权给付费方。职务开发也有适用条件。对AI玩具，还要分别处理角色形象、语音素材、开源代码、模型许可、硬件设计与模具；获得某部分使用权，不代表取得全部所有权或全球再授权。境外融资时再转移IP，可能带来估值、税务和技术进出口问题，应在结构设计前核实。

依据：[5] [计算机软件保护条例](<https://xzfg.moj.gov.cn/mobile/law/detail?LawID=581>)

## 境外融资、收款与资金路线

> **一个与当前办理时间直接相关的更新**
>
> 2026-07-01已施行的《国务院关于对外投资的规定》已把境内居民个人列入投资者范围。2026-10-16公布的新《对外投资管理办法》要到2026-12-01才施行。不能依据旧攻略断言“个人直接持有海外公司就无需管对外投资”；也不能把12月的配套程序当作11月已经实施。注册、出资或转移IP前，应按身份、资产来源、目的和办理日期向专业人员、主管部门及银行核清。

依据：[42] [国务院关于对外投资的规定（司法部法规库）](<https://xzfg.moj.gov.cn/mobile/law/detail?LawID=1818>) · [43] [发改委：对外投资管理办法](<https://zfxxgk.ndrc.gov.cn/wap/iteminfo.jsp?id=20667>)

**不同路线，核验的重点不同**

| 拟采用的路线 | 要先回答的问题 |
| --- | --- |
| 个人直接持有境外公司 | 是否属于境内居民个人；资金／资产从哪里来、何时投入；当前对外投资、外汇与个人税务要求分别如何适用 |
| 居民个人设境外SPV融资并返程控制深圳公司 | 是否符合37号文的SPV定义，出资前登记、后续变更和返程投资怎样办理；不是给任何海外公司贴一个“37号文”标签 |
| 深圳公司出资设香港／海外子公司 | 企业对外投资的发改、商务及银行／外汇程序如何分工；不能用个人SPV登记代替企业手续 |
| 融资款或其他资金进入深圳 | 究竟是股权投资、股权收购、跨境借款，还是有真实交付的货款／研发服务费；按真实性质配套办理和记账 |
| 境外公司与深圳公司交易 | 谁拥有资产、承担库存和售后风险、提供研发与运营；合同、价格、发票与付款依据怎样解释 |
| 公司或创始人取得境外利润 | 公司实际管理机构、个人税务居民、收入性质、协定及境外税收抵免分别怎么判断；不能照搬美国LLC的透明税务分类到中国 |
