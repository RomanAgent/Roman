# Raystar 曜凌光电

Raystar面向中小尺寸显示，提供字符和图形OLED、单色LCD、TFT及嵌入式显示集成。它对乐器效果器、桌面创作工具和小型控制界面的价值在于将屏幕、输入、接口和驱动共同讨论；这不同于只卖裸面板，但系统集成范围仍以显示交互为主，不能视为完整AI终端代工或算法服务。
