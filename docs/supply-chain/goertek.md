# Goertek / 歌尔

歌尔的公开范围同时包含声学、光学等精密零件与智能整机，其家庭业务明确提到AI音箱和安防，从工业设计延伸至测试及量产。它适合声学与外观空间耦合较强的终端研究，但不能把零件制造经验直接视为任意陪伴机器人或具体品牌的供货证据。

## 公司定位与边界

### 公开定位 · 官方资料

歌尔官网将声学、光学、微电子和外壳等零组件，与可穿戴、音频、家庭及扩展现实整机一起介绍。它不是只做一个麦克风的公司，也不能据此理解为每种家庭机器人的全部机构和算法都可由其直接交付。

依据：[歌尔公司简介](<https://www.goertek.com/en/about/intro.html>)

### 合作边界判断 · 研究判断

对家庭AI终端，歌尔的独特讨论点在于声音输入输出与物理结构可以共同设计。若创业产品靠细腻声音和触觉反馈形成体验，值得了解其跨模块协作方式；但用户关系、内容和行为策略仍需要产品团队自己定义。
