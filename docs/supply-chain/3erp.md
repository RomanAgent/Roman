# 3ERP

3ERP 是位于广东中山的原型及低批量制造服务商，公开覆盖机加工、真空复模、注塑、压铸、钣金和增材制造。适合验证家用 AI 硬件的结构、触感及装配，不应将工艺范围视作整机安全或算法能力证明；样件与量产工艺差异需要逐项记录。
