# Mistral AI

基础模型 · 法国 · 核查 2026-11-05

Mistral以Vibe提供个人和团队工作及编码代理，以Studio提供模型与应用开发能力，并为企业提供定制部署路径；本条重点是任务入口和部署控制的组合，避免沿用只有聊天或只有权重发布的旧定位。

**业务入口：公开产品入口**。原Le Chat入口现指向Vibe，官方文档区分Vibe、Studio和Admin；免费、付费和企业方案并存，部分连接功能明确Beta。

公司与集团：Le Chat历史品牌、Vibe、Studio及模型族均归于Mistral AI，不把命名更新拆成公司；模型伙伴或企业部署渠道不视为公司归属变化。

地区口径：按Mistral AI法国公司业务口径记录；私有部署、云处理区域和合同主体须分别核查，不能仅凭欧洲品牌推定所有数据留欧。

## 重点产品

### Mistral Vibe（原 Le Chat）

应用 · 已公开提供

将对话、资料工作和编码任务放在共同代理入口中，支持通过所连接知识与工具推进任务；旧Le Chat名称保留为历史检索别名。

目标用户：希望完成研究、内容工作与软件任务的个人和协作团队。

AI作用：模型结合检索和连接工具推进工作，编码代理可进入开发环境；任务规划不代表无需人工复查，连接器的权限和成熟度影响实际能力。

使用与交付：提供网页、移动及编码工具等使用路径，连接器、组织功能和私有部署依具体方案配置。

收费形式：有有限免费、个人和团队订阅及企业定制方案，部分套餐含有限API额度，超额及公平使用条件需另核。

产品边界：部分连接能力标为Beta，企业私有部署不能套到普通免费账号；套餐额度、模型和入口可能更新，不能把长期任务描述理解为任意任务保证成功。

### Mistral Studio / 模型 API

平台 · 已公开提供

为开发者提供控制台、模型接口、评估及代理开发入口，把生成、文档或音频等能力嵌入自己的应用，并通过组织管理配置访问。

目标用户：需要模型调用、文档处理或自有代理开发的软件团队。

AI作用：模型分别承担语言、代码、文档与音频理解生成，平台组织评估和应用开发；不同模型和部署方式的能力及许可不统一。

使用与交付：通过Studio控制台、API及SDK交付，企业自托管或定制部署需另按模型和方案确认。

收费形式：多数模型按输入输出token计费，OCR、语音和工具采用不同单位；适用套餐credits与独立使用量仍需核对。

产品边界：开放权重不等于所有商业使用条件一致，需逐模型读许可；API和私有部署还涉及资源、维护及数据条款，不能用一个套餐概括全部费用。

## 产品与工作流

### 事实｜Studio与Admin承担不同平台工作 · 官方资料

官方文档将Studio作为开发控制台与API入口，包含密钥、试验、评估和代理相关能力，Admin负责组织、账单及访问策略。这样的划分有助于区分应用开发与治理，但仍需团队配置；不是用户打开Vibe后就自动拥有全部后台管理流程。

依据：[Mistral官方平台文档](<https://docs.mistral.ai/>)

### 判断｜工作与代码衔接需要可检查的产物 · 研究判断

研究、文稿和软件任务连接起来后，产物应能被回看、继续编辑和验证，不能只留在聊天记录里。远程编码或多步骤工作可能减少切换，也可能增加状态理解成本；评价应检查用户怎样接管和修正，而不是把代理运行时间长视为更高质量。

依据：[Mistral Vibe当前产品页](<https://mistral.ai/products/vibe/>) · [Mistral当前方案及API计费说明](<https://mistral.ai/pricing/>)
