## 重点产品

### DeepSeek 模型与检索 API

平台 · 已公开提供

向开发者提供支持推理和工具调用的模型接口，并另有网页搜索及抓取服务，团队可在自己的应用中组合资料获取、生成和执行流程。

目标用户：需要推理、代码和资料处理能力的软件开发者及企业团队。

AI作用：模型依据上下文进行推理、生成及工具调用，搜索抓取补充外部资料；当前不同型号的视觉支持并不一致，不能用产品族名称统一推断。

使用与交付：通过官方账户、API和兼容客户端调用，思考模式、模型标识和独立检索接口需按文档配置。

收费形式：按输入输出及缓存等用量收费，当前有峰谷规则；Search和Fetch为独立按请求计费接口，不默认包含在每次模型调用中。

产品边界：旧别名可能映射到新版本，需固定评测并追踪变化；思考输出更长不代表更正确，检索结果仍需核源，费用和模型支持以当前账户与文档为准。
