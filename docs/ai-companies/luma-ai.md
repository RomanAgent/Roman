## 重点产品

### Luma Agents 媒体生成与编辑 API

平台 · 已公开提供

通过统一异步接口生成和编辑图像视频，开发者可提交源素材及关键帧来控制视频改稿，再取得结果继续进入制作管线。

目标用户：构建创意工具、广告素材流程和媒体制作系统的开发者。

AI作用：视频编辑按新提示重绘源片段，并可用关键帧和保持控制指导变化；图像视频生成共享接口形式，但底层任务限制仍分别适用。

使用与交付：使用平台密钥提交任务、轮询状态并下载结果，用户侧需要管理文件、失败恢复及输出保存。

收费形式：以信用点按操作和设置收费，信用点美元换算依账户方案或合同；预留吞吐与共享用量的条件不同。

产品边界：价格文档提示视频费用在正式开放前可能变化，不能把旧应用订阅当新 API 权益；重绘非无损剪辑，中国大陆交付条件本轮未验证。

## 需求与市场

### 保留运动的改稿 · 研究判断

视频创作者有时希望保留已经合适的动作，只改变风格或局部外观，重新拍摄或从零生成都会浪费已有成果。Luma 的视频编辑针对这一需求，但技术上是重绘，必须检查原动作和关键内容是否真的保持，不能按无损编辑理解。

依据：[视频编辑文档](<https://docs.agents.lumalabs.ai/guides/videos/editing/>)

### 统一媒体管线 · 研究判断

开发团队希望用相似任务机制处理图像和视频，降低不同工具的接入复杂度。统一接口有助于这一目标，但需求价值仍由生成结果是否可用决定；如果素材管理和审核还很分散，接口统一并不会自动形成完整生产流程。

依据：[Luma Agents 快速开始](<https://docs.agents.lumalabs.ai/>)

## 目标用户

### 制作人员 · 研究判断

有明确镜头意图的创作者更能利用关键帧控制，因为他们知道哪些时刻必须保留构图或角色。完全没有分镜思路的用户可能只得到大量变化；产品应帮助他们表达约束，而不把所有失败都解释成提示还不够详细。

依据：[视频编辑文档](<https://docs.agents.lumalabs.ai/guides/videos/editing/>)

### 平台购买者 · 研究判断

开发者和企业媒体平台会关注请求容量、延迟和数据使用承诺，使用量稳定时才可能考虑预留资源。偶尔生成的个人与持续批量调用的团队不应按同一成本方式比较，账户合同还可能改变信用点的实际货币价值。

依据：[接口计费与容量](<https://docs.agents.lumalabs.ai/guides/pricing/>)

## 产品与工作流

### 异步交付 · 研究判断

官方流程是提交生成、查询状态并在完成后下载，说明调用完成需要多个阶段。客户应用必须保存任务标识、解释等待并处理失败，不能把提交成功显示为作品已完成；结果下载与长期素材保管也应在自己的流程中明确。

依据：[Luma Agents 快速开始](<https://docs.agents.lumalabs.ai/>)

### 关键帧改稿 · 研究判断

源视频和指定时刻的引导图共同定义修改意图，比单句风格提示提供更多约束。实际制作仍要逐段检查相邻关键帧之间的过渡，模型可能在中间生成不希望的变化，因此验收不能只看被钉住的几张参考画面。

依据：[视频编辑文档](<https://docs.agents.lumalabs.ai/guides/videos/editing/>)

## AI技术与依赖

### 条件化重绘 · 研究判断

文档明确视频编辑根据新提示重绘原视频，保持强度和控制信号影响结果。它不是传统剪辑器里的像素锁定，改变设置可能同时影响主体与背景，技术评估应分别考察动作保留、身份一致和视觉改动，而非只判断风格接近。

依据：[视频编辑文档](<https://docs.agents.lumalabs.ai/guides/videos/editing/>)

### 接口迁移 · 研究判断

旧 Dream Machine 文档已经引导到新 Agents 平台，集成者需要核对认证、任务结构和模型支持。名称连续不代表旧代码与套餐全部兼容，迁移应通过实际样本和错误处理测试，而不能仅替换域名就视为完成升级。

依据：[Luma Agents 快速开始](<https://docs.agents.lumalabs.ai/>) · [旧 Dream Machine 文档入口](<https://docs.lumalabs.ai/docs/welcome>)

## 竞争与替代

### 替代生产方法 · 研究判断

传统合成和三维重渲染提供更严格控制但需要更多专业操作，生成式视频编辑可以缩短某些改稿。选择取决于镜头能接受多少变化，若包装文字或真实动作必须完全保真，人工合成可能仍是更可靠且容易验收的办法。

依据：[视频编辑文档](<https://docs.agents.lumalabs.ai/guides/videos/editing/>)

### 平台选择 · 研究判断

其他媒体 API 也提供生成和编辑，Luma 的差异需要在关键帧约束、动作保持和整合成本上证明。统一接口只是基础便利，真正影响长期采用的是失败可诊断、结果可重复以及团队能否把它接入现有素材审核体系。

依据：[Luma Agents 快速开始](<https://docs.agents.lumalabs.ai/>)

## 商业模式

### 按操作计费 · 研究判断

生成、编辑、延长和重新构图采用不同费用结构，因此同样的视频秒数不代表同样成本。报价应按真实制作路径组合计算，并包括重试与人工挑选，不能用最低草稿单价代表高分辨率编辑或带额外格式导出的整个项目。

依据：[接口计费与容量](<https://docs.agents.lumalabs.ai/guides/pricing/>)

### 容量合同 · 研究判断

预留吞吐提供更可预测容量和特定承诺，但也存在最低承诺与期限，适合有稳定需求的买方。共享按量方案更灵活，却不能自动享有相同保证；商业比较应同时考虑闲置资源和排队损失，而不是只看每张图的换算价格。

依据：[接口计费与容量](<https://docs.agents.lumalabs.ai/guides/pricing/>)

## 体验与交付

### 控制可理解性 · 研究判断

关键帧、保持强度和自动控制提供丰富调节，也会增加学习负担。界面若能展示每项控制影响哪个时刻和内容，更容易让创作者收敛意图；否则用户可能盲目调参，把时间花在无法解释的输出变化上。

依据：[视频编辑文档](<https://docs.agents.lumalabs.ai/guides/videos/editing/>)

### 验收场景 · 待验证

建议使用含人物转身、遮挡和商品近景的短片测试编辑，逐帧比较关键细节并统计修复时间。接口还应测试超时、失败、下载及容量波峰，国内网络与账户付费本轮未实测，不能仅凭文档开放承诺完整交付。

依据：[Luma Agents 快速开始](<https://docs.agents.lumalabs.ai/>) · [接口计费与容量](<https://docs.agents.lumalabs.ai/guides/pricing/>)

## 风险与机会

### 开放与承诺 · 研究判断

视频价格仍有正式开放前调整提示，预留容量和按量使用的数据承诺也不同。机会是为稳定生产提供明确控制和合同选择，风险是客户把预览费用或某个方案的承诺当成全平台固定规则，导致上线后预算与数据预期不符。

依据：[接口计费与容量](<https://docs.agents.lumalabs.ai/guides/pricing/>)

### 持续更新 · 待验证

后续应跟踪新旧接口迁移和视频能力开放状态，同时保留源片、关键帧与参数以便复现问题。输出逼真不代表保留了事实，涉及真实人物和商品的项目仍需审核，不能将模型的视觉连贯性视作内容准确或授权充分的证明。

依据：[旧 Dream Machine 文档入口](<https://docs.lumalabs.ai/docs/welcome>) · [视频编辑文档](<https://docs.agents.lumalabs.ai/guides/videos/editing/>)
