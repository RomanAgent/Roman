## 重点产品

### Grok 模型与工具 API

平台 · 已公开提供

向开发者提供文本、代码和多模态模型接口，并结合网页、X内容、代码执行及资料集合等工具构建检索与生成工作流。

目标用户：需要实时资料处理、多模态生成或代理能力的软件开发团队。

AI作用：模型负责理解、推理和生成，检索工具提供外部信息，代码及其他工具执行可验证步骤；检索结果仍需进行来源和时效判断。

使用与交付：通过开发控制台、API和SDK交付，模型与工具资格依账户、地区及具体接口而异。

收费形式：模型按token或媒体单位计费，服务端工具及存储另有费用，长上下文和区域端点规则须单独核算。

产品边界：网页或X检索不保证信息真实完整，工具调用成本随任务复杂度增长；不同模型、接口和地区条件不一致，历史版本或退役项不能当当前可用。
