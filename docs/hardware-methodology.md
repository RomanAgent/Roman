# 市场目录的研究方法

本目录是全球 AI 智能硬件的**首轮代表性案头研究**，核查日期为 2026-11-04。不是全市场 SKU 普查、销量排行榜或投资评级。不同内存、颜色、地区包和订阅组合一般合并为一个产品 / 系列，能影响能力边界的版本在条目内单独说明。

## 收录与排除

纳入具有明确生成式对话、视觉 / 行为识别、学习决策或 AI 开发用途的实体设备。仅支持联网、定时控制或遥控，不足以认定为 AI 硬件。开发平台与通用手机 / 电脑单列，它们既是产品，也可能是独立硬件的替代方案。

- **在售**：有当前官方购买入口或明确授权渠道。核查未完成支付或收货，不能保证每个地区、尺码、颜色均有现货。
- **预售 / 延期交付**：官方接受预订或 backorder，交付承诺尚未经验证。延期销售不等于新品首发预售。
- **待复核**：只有发布或展示页、库存冲突、售罄，或购买入口无法核验，不计入可购产品数。
- **停售**：有停止销售或服务退出证据，留在观察样本中，不出现在默认可购结果里。

售价保留原币种、地区、配置、优惠门槛及订阅条件。不能把以旧换新价当无条件售价，也不把发布时起价当当前到手价。不进行无汇率依据的价格排名。

## 每款产品的分析结构

1. 需求与市场：任务、替代做法、可能的付费理由，标为需求假设。
2. 用户画像：按使用任务、预算、能力与渠道限制推断，不虚构用户年龄占比或购买数据。
3. 竞争与替代：同类设备及手机、电脑、人工服务等替代方案。
4. 供应链：公开元件与平台、装配校准、认证、维修及云服务依赖。未披露的工厂、采购合同、产能与 BOM 不当事实写。
5. 技术路径：输入、模型、计算部署、执行、联网与订阅依赖；区分厂商声明与独立验证。
6. 产品审美：结构、交互、佩戴或摆放方式与长期使用体验的设计观察。
7. 关键风险：具体地区、版本、可靠性、成本和交付的不确定性。
8. 市场空间：差异化购买理由与需要继续验证的条件，不给成功概率。

## “冷门”如何判断

采用定性分类，而不制造精确分数：

| 分类 | 含义 | 不代表什么 |
| --- | --- | --- |
| 竞争密集 | 成熟替代、多品牌及渠道竞争 | 不代表没有机会 |
| 新兴竞争 | 产品形态或场景仍在变化 | 不代表低风险或用户一定需要 |
| 细分专业 | 任务、用户范围较窄，往往有技术与交付门槛 | 不代表蓝海、竞争少或高利润 |

这些是基于本轮样本的研究判断，**没有进行完整竞争者普查或市场份额统计**。

## 图示的证据边界

网页的功能分层图只表达系统关系，**不是实物拆机、真实空间布局、制造图或已验证 BOM**。每一层标明“官方披露”或“分析推断”。有可核查官方装配资料时，额外链接原图与装配说明并注明来源；不把 AI 生成图当作实物证据。

## 这轮尚未完成的实证工作

没有开展用户访谈、问卷抽样、真实下单、实物测试、拆机、供应商报价、销量审计或留存研究。厂商页面能支持功能声明和购买入口，但不能独立证明准确率、可靠性或用户需求。

工业 / 商业机器人、医疗与辅助设备、汽车与无人机、手机电脑及家电长尾、众筹预售长尾尚未穷尽。下一轮应按品类扩大核查，并补用户任务访谈、替代方案测试、退货原因及维修成本。

## 更新与复用

- 研究源文件：`content/hardware/research-*.json`。

- 生成目录：运行 `npm run catalog`，生成网页 `catalog.json` 与 GitHub Markdown。
- 验证：运行 `npm run check`。
- 目前没有后台自动监控库存；每次人工复核后更新对应 `checkedAt` 和来源。
