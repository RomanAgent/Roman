# 市场目录的研究方法

本目录是面向**个人、家庭与个人创作者的全球消费级 AI 智能硬件案头研究**，核查日期为 2026-11-04。不是全市场 SKU 普查、销量排行榜或投资评级。不同内存、颜色、地区包和订阅组合一般合并为一个产品 / 系列，能影响能力边界的版本在条目内单独说明。

## 收录与排除

纳入具有明确生成式对话、视觉 / 行为识别、学习或博弈决策功能，并且个人可以购买使用的实体电子设备。需要有感知、计算、交互或执行部件；纯 App、无电子的识别道具、仅联网、定时控制或遥控的普通设备不计入。AI 可以在设备、手机或云端运行，但必须写明依赖关系。

消费身份以最终使用者和购买渠道判断，不单以价格高低决定。面向个人的助听器可通过验配渠道销售；家用健身设备和个人创作工具也可纳入。医院、企业或科研专用设备及纯开发板移入[专业档案](hardware-professional-archive.md)，不计入消费目标。通用手机与电脑保留单独分类，作为专用设备的替代方案。

**200 款目标只统计在售或预售的 consumer / prosumer 产品**。待复核、停售及专业档案均不计入；同款配色、容量、尺寸及组合包不重复凑数。常规零售、个人验配和预售分别标记。

- **在售**：有当前官方购买入口或明确授权渠道。核查未完成支付或收货，不能保证每个地区、尺码、颜色均有现货。
- **预售 / 延期交付**：官方接受预订或 backorder，交付承诺尚未经验证。延期销售不等于新品首发预售。
- **待复核**：只有发布或展示页、库存冲突、售罄，或购买入口无法核验，不计入可购产品数。
- **停售**：有停止销售或服务退出证据，留在观察样本中，不出现在默认可购结果里。

售价保留原币种、地区、配置、优惠门槛及订阅条件。不能把以旧换新价当无条件售价，也不把发布时起价当当前到手价。不进行无汇率依据的价格排名。

## 每款产品的分析结构

1. 需求与市场：任务、替代做法、可能的付费理由，标为需求假设。
2. 用户画像：按使用任务、预算、能力与渠道限制推断，不虚构用户年龄占比或购买数据。
3. 竞争与替代：同类设备及手机、电脑、人工服务等替代方案。
4. 供应链：公开元件与平台、装配校准、认证、维修及云服务依赖。未披露的工厂、采购合同、产能与 BOM 不当事实写。
5. 技术路径：输入、模型、计算部署、执行、联网与订阅依赖；区分厂商声明与独立验证。
6. 产品审美：结构、交互、佩戴或摆放方式与长期使用体验的设计观察。
7. 关键风险：具体地区、版本、可靠性、成本和交付的不确定性。
8. 市场空间：差异化购买理由与需要继续验证的条件，不给成功概率。

## “冷门”如何判断

采用定性分类，而不制造精确分数：

| 分类 | 含义 | 不代表什么 |
| --- | --- | --- |
| 竞争密集 | 成熟替代、多品牌及渠道竞争 | 不代表没有机会 |
| 新兴竞争 | 产品形态或场景仍在变化 | 不代表低风险或用户一定需要 |
| 细分专业 | 任务、用户范围较窄，往往有技术与交付门槛 | 不代表蓝海、竞争少或高利润 |

这些是基于本轮样本的研究判断，**没有进行完整竞争者普查或市场份额统计**。

## 图示的证据边界

每款产品的图片分为三类：对应型号的真实产品图、官方或注明出处的参考图、使用内置 ImageGen 单独生成的 AI 爆炸示意。原图保留源页面与原始图片链接，AI 图保存实际提示词、生成日期及参考图片。

**AI 爆炸示意不是实物拆机、真实空间布局、制造图或已验证 BOM**。已公开的外形与功能用作参考，隐藏结构只作概念推断；图内标明 AI CONCEPT / NOT A TEARDOWN，图外再作中文标识。不会通过生成图确认芯片、供应商、螺钉数量、尺寸或维修步骤。文字功能分层保留在折叠区域，可对照“官方披露”和“分析推断”。

有官方装配图时作为独立图源提供，不与 AI 生成图混同。品牌图库或媒体配图的版权归原权利人，来源显示在图片旁；图中营销描述不等于本目录独立验证。

## 这轮尚未完成的实证工作

没有开展用户访谈、问卷抽样、真实下单、实物测试、拆机、供应商报价、销量审计或留存研究。厂商页面能支持功能声明和购买入口，但不能独立证明准确率、可靠性或用户需求。

全球消费品的地区型号、可访问渠道及预售长尾尚未穷尽。助听、无障碍、睡眠、宠物照护、家用能源、音乐与实体对弈等已扩展为独立分类；单个类别的样本数量仍不代表市场规模。下一轮应补用户任务访谈、替代方案测试、退货原因及维修成本。企业采购和科研开发不属于本消费目录的目标范围。

## 更新与复用

- 研究源文件：`content/hardware/research-*.json`。
- 分类与边界：`content/hardware/metadata.json`。
- 生成目录：运行 `npm run catalog`，生成网页 `catalog.json` 与 GitHub Markdown。
- 验证：运行 `npm run check`、`npm run media:check` 和 `npm run target:check`。
- 目前没有后台自动监控库存；每次人工复核后更新对应 `checkedAt` 和来源。
